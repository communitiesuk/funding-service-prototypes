Journeys

The driver for this functionality is that when grant recipients need access to forms or reports, they have to contact the support desk. This is an offline process and involves waiting until MHCLG can check and action the request.

The new functionality designed here allows users in existing organisations to request access to forms and reports. It also allows existing users to add or remove team members.

These journeys were tested with 5 local authority and charity users in August 2026.

Request access - User does not have access to the grant

Request access - User with LA email requests access for an existing organisation

Request access - User with a non-LA email requests access for a form or report

Add and remove users

Next steps

These are items that were raised in the user research but require further exploration before implementing. We will monitor after release:

  • Consider adding admin role who can add and remove users
  • Consider adding view-only role ('Reviewer'?) who cannot add or remove users and cannot edit or submit
  • Consider language of roles: 'can edit and submit' and 'certifier'
  • If other users can add and remove users, the admin gets notified of changes.
