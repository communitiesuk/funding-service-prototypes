Journeys

An applicant signs up on behalf of their organisation for a competed grant on Access grant funding. Competed grants are those where MHCLG do not invite specific organisations to apply so anyone in any organisation can apply.

All organisations

Start an application (from Find a Grant)

In the example, the entry point is Cabinet Office's 'Find a grant' service.

Start an application (from grant landing page)

Users could also come through other entry points, such as a colleague sharing a direct link to the grant landing page.

The grant description is automatically generated when a form designer enters it in Deliver grant funding. A prospectus link will only show if it is provided.

Check eligibility

Whether an organisation is new or existing, they have to check their eligibility for each grant. The eligibility questions are examples only and change for each grant.

New organisation

Create an organisation (new journey)

After the eligibility check, users with email domains not linked to an organisation in Access grant funding must create an organisation by entering their details.

Existing organisation

User's email domain is linked to one or more existing organisations

After the eligibility check, users with email domains linked to one or more existing organisations can choose from those organisations.

In the example:

  • 'Lewes District Council' shows the journey for users in existing organisations do not have an account, and an application has not started yet
  • 'Eastbourne Borough Council' shows when someone else from the existing organisation has already started an application (user must contact our support desk)

If the organisation does not appear in the list, users can 'Apply on behalf of another organisation' (directs to 'Create an organisation').

Existing user accesses an application form that has not been started

If a user already has an account in Access grant funding, they will automatically get added to the organisation for the grant they're applying for.

They will be directed to the dashboard page to start the form.
